# Segurança

## Versões suportadas

Somente a versão principal mais recente recebe correções de segurança.

## Comunicação responsável

Não abra uma issue pública com documentos confidenciais, caminhos pessoais, credenciais ou detalhes que facilitem a exploração de uma falha. Use o recurso **Report a vulnerability** na aba Security do repositório GitHub.

Inclua a versão do HollyOCR, o sistema operacional, uma descrição reproduzível e o impacto observado. Use apenas arquivos de teste sem dados pessoais.
